
About this Project
=======
This project aims to facilitate the implementation of many common features found in various mods, including functionality related to `Attachments`, GUI, data saving, and much more!

This project is planned to be updated in future versions, starting from Minecraft 26.3.

There are no plans to create a project compatible with **Minecraft Rust Edition** (until Mojang decides what to do with that project).

First steps
=======

Download the latest available version from the [Releases](https://github.com/Gianka1485/MC-Enhanced-LIB/releases) each new version includes bug fixes and new features designed to maintain compatibility, improve performance, and enhance usability. If you encounter any issues related to compatibility with older versions, please consult the [Changelog](https://github.com/Gianka1485/MC-Enhanced-LIB/commits/main/) or report the error at https://github.com/Gianka1485/MC-Enhanced-LIB/issues.
